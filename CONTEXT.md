# iweb Product Context

iweb gives a non-technical owner one personal node where an AI coding agent can deploy and operate applications without requiring the owner to understand containers, databases, or network operations.

## Language

**Node owner**:
The non-technical person who owns one iweb node and delegates application development and operation to an AI coding agent.
_Avoid_: Operator, developer, tenant

**Personal node**:
The owner's durable control boundary containing the trusted management plane and multiple mutually isolated applications.
_Avoid_: Shared app container, trusted household runtime

**Application package**:
Code and assets submitted for execution, potentially copied from the internet or generated by AI, and untrusted by default regardless of who submitted it.
_Avoid_: Trusted workspace app, Dispatcher branch

**Application sandbox**:
One application's exclusive execution, credential, storage, network, resource, and lifecycle boundary. A sandbox failure or compromise must not cross into another sandbox or the node control plane.
_Avoid_: Route, handler, V8 isolate

**Node control plane**:
The trusted Kernel, Admin, and MCP authority that authenticates the owner and creates, observes, updates, and removes application sandboxes without sharing its credentials with them.
_Avoid_: User application, system route

**Deployment agent**:
An owner-authorized AI coding agent that uses MCP to turn an application package into a validated sandbox deployment.
_Avoid_: Application process, end user
